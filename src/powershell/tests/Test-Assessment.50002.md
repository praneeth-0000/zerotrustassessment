The Microsoft Cloud Security Benchmark (MCSB) is a comprehensive set of cloud-agnostic security best practices published by Microsoft, organized into control domains such as Network Security (NS), Identity Management (IM), Privileged Access (PA), Data Protection (DP), Asset Management (AM), Logging & Threat Detection (LT), Incident Response (IR), Posture & Vulnerability Management (PV), Endpoint Security (ES), Backup & Recovery (BR), DevOps Security (DS), and Governance & Strategy (GS). Microsoft Defender for Cloud continuously evaluates your Azure resources against these MCSB controls and produces per-resource compliance assessments. Each assessment maps a specific resource to one or more MCSB controls and reports its state (healthy, unhealthy, or not applicable) alongside remediation guidance. The MCSB control ID column (e.g., PA.1, NS.5, LT.3) identifies which benchmark requirement the finding relates to, allowing you to directly address specific compliance gaps and demonstrate alignment with frameworks such as CIS, NIST SP 800-53, PCI-DSS, and ISO 27001.
